# Демонстрационное приложение ASP.NET 9 + Redis к открытому уроку OTUS

Демо-приложение, показывающее различные сценарии использования Redis в ASP.NET Core приложениях.

## 🚀 Возможности

- **Кэширование** - базовые операции с ключ-значение
- **Распределённый кэш** - через стандартный `IDistributedCache`
- **Счётчики** - атомарные инкременты
- **Pub/Sub** - публикация и подписка на сообщения
- **Распределённые блокировки** - координация между экземплярами приложения

## 📋 Предварительные требования

- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- [Docker](https://docker.com) (рекомендуется) или установленный Redis сервер

## 🛠️ Быстрый старт

### 1. Запуск Redis

```bash
# Запуск Redis в Docker
docker run -d -p 6379:6379 --name redis-demo redis:7-alpine

# Или используйте существующий Redis сервер
```

### 2. Настройка подключения (опционально)

По умолчанию приложение подключается к `localhost:6379`. Для изменения:

```bash
# Linux/Mac
export REDIS_CONNECTION="your-redis-host:6379,password=your-password"

# Windows
set REDIS_CONNECTION="your-redis-host:6379,password=your-password"
```

### 3. Запуск приложения

```bash
# Клонирование репозитория (если есть)
git clone <repository-url>
cd <project-directory>

# Восстановление зависимостей
dotnet restore

# Запуск приложения
dotnet run
```

Приложение будет доступно по адресу: `https://localhost:5000` (или `http://localhost:5000`)

OpenAPI документация по адресу: `https://localhost:5000/swagger` (или `http://localhost:5000/swagger`)

## 🏗️ Архитектура

### Используемые технологии

- **ASP.NET Core 9** - веб-фреймворк
- **StackExchange.Redis** - клиент Redis для .NET
- **IDistributedCache** - абстракция распределённого кэша

### Ключевые компоненты

- `RedisService` - сервис-обёртка для Redis операций
- `RedisSubscriber` - фоновая служба для обработки сообщений
- Контроллеры - API endpoints для демонстрации возможностей

## 🔧 Конфигурация

### Параметры Redis

Поддерживаемые форматы строки подключения:

```
localhost:6379
redis-server:6379,password=secret,abortConnect=false
127.0.0.1:6379,ssl=true,password=secret
```

### Переменные окружения

- `REDIS_CONNECTION` - строка подключения к Redis

## 🚨 Обработка ошибок

Приложение обрабатывает следующие сценарии:

- **404** - ключ не найден в кэше
- **409** - не удалось захватить блокировку (уже занята)
- **400** - неверные параметры запроса
- **500** - внутренние ошибки Redis

## 📊 Мониторинг

### Проверка состояния Redis

```bash
# Подключение к Redis CLI
docker exec -it redis-demo redis-cli

# Проверка статистики
redis-cli info memory
redis-cli info keyspace
redis-cli monitor
```

### Ключи в Redis

Приложение использует следующие паттерны ключей:

- `{key}` - простой кэш
- `demo:counter` - счётчик
- `lock:{key}` - блокировки
- Каналы Pub/Sub - по именам каналов

## 🔒 Безопасность

- Используйте пароль для Redis в продакшене
- Настройте брандмауэр для ограничения доступа к порту Redis
- Используйте SSL/TLS для защищённого соединения
